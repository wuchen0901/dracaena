# 《灯下》美术规范

## 风格定位

**废弃维多利亚宅邸铜版画**：像一本旧探险手册里的手绘插图。画面安静、克制，带有神秘感和轻微荒诞感。整体以侧面剖开的房间呈现空间，使用不规则钢笔轮廓、有限的交叉排线、旧木与石材质感，以及局部暖灯照明。

这套风格面向游戏实际画面：角色、机关和危险物必须在小尺寸下清楚可辨；纹理帮助建立材质，不应盖过轮廓和玩法信息。

## 色板

| 色彩 | 色值 | 用途 |
| --- | --- | --- |
| 墨绿黑 | `#252B29` | 画面底色、最深处阴影、轮廓 |
| 苔灰绿 | `#42483D` | 石墙、金属和冷暗结构 |
| 烟熏橄榄灰 | `#77735C` | 旧石材、门闩、灯具外壳 |
| 旧黄铜 | `#AD9873` | 木作描边、次要高光、界面辅助色 |
| 羊皮纸 | `#D8C6A0` | 文字、亮面细节和灯罩反光 |
| 灯芯赭金 | `#C18A49` | 主灯、出口、主角雨衣的识别色 |

基础环境保持低饱和。暖色只集中在灯、出口和少量交互提示；冷色月光使用灰绿，不引入蓝紫霓虹色。死亡或危险提示以赭金和明暗变化表达，不使用鲜红 UI。

## 造型与透视

- 房间使用固定的正侧面剖视，让平台、墙、梯子和机关的关系一眼可读。
- 墙面、柜体和门框用接近直线的手绘轮廓，允许轻微不均匀，不做圆润卡通外形。
- 道具使用简洁的大形和少量结构线；避免微小装饰、复杂花纹或写实透视造成视觉噪声。
- 主角保持小巧、纤细，以赭金雨衣形成稳定识别点；面部细节克制。
- 影子优先呈现为深墨色剪影。被照亮后转为旧家具，材质改成暗木、黄铜和羊皮纸色表盘。

## 线条、阴影与材质

- 线条像钢笔或蚀刻线：深、细、略有变化；避免纯黑粗描边包住所有物体。
- 阴影以大块明暗为主，局部使用短排线或交叉排线。排线方向可随石块、木板和布料变化。
- 石墙用不规则砖缝和稀疏短排线；木地板用板缝、细木纹；护墙板用竖向分格；金属机关用少量磨损边缘。
- 旧纸和颗粒感应轻而稳定。不要在每帧随机生成噪点，避免闪烁，也不要让纹理降低碰撞边界的可读性。

## 光照与氛围

- 环境处于暗部，但仍保留苔灰绿和旧木色层次，不能把未照亮区域压成纯黑。
- 主光源是暖黄灯，光晕柔和且局部；灯光需要明确说明“哪里安全、哪里危险”。
- 窗外月光采用低亮度灰绿，只作为冷暖对照，不与主灯争夺焦点。
- 画面边缘可以轻微压暗，中心区域保持足够对比，确保小屏上看清玩家、影子和机关。

## 界面与交互

- UI 使用羊皮纸色文字、旧黄铜色细边和半透明深绿底，不使用霓虹描边或现代玻璃拟态。
- 关卡进度点、按钮和提示沿用主色板；当前关卡和可交互对象可提高亮度，不额外引入新强调色。
- 操作提示清晰、简短，放在场景之外的稳定区域；避免覆盖角色、灯和出口。

## 生成素材时的统一提示

> 2D 横版解谜游戏《灯下》的美术素材。废弃维多利亚宅邸，固定正侧面剖视，低饱和棕绿配色（`#252B29`、`#42483D`、`#77735C`、`#AD9873`、`#D8C6A0`、`#C18A49`），钢笔手绘轮廓、克制的铜版画排线、旧纸与磨损木石材质，暗部保留层次，局部暖黄灯光与灰绿月光。造型简洁、轮廓清晰、适合小尺寸游戏画面。不要蓝紫霓虹、鲜艳高饱和色、厚重卡通描边、照片写实质感、文字或 UI。

## 交付检查

每个新素材都检查：

1. 色彩是否落在既定色板及其明暗变化范围内。
2. 视角是否符合正侧面剖视，是否和已有房间的比例一致。
3. 轮廓是否清晰，缩小后能否立即识别用途和危险性。
4. 排线和纹理是否克制，是否仍以大形和明暗关系为主。
5. 暖光是否只用于灯、出口和必要的交互焦点。
