# Reclamation station escape

The playable journey now starts at x=-3550 with a factory alarm and a stream of identical robots fleeing along an elevated conveyor. They run into the open reclamation chute one by one. The protagonist is separated from them and continues along the lower maintenance passage, leaving him as the only robot still moving when the route reaches the checkpoint at x=-2600. The player keeps normal movement and jump control; there is no timed chase, failure state, exposition dialog or cutscene.

The first automatic save is “工厂 · 警报响起”; reaching the end of the stampede creates “工厂逃亡 · 只剩主角”. Older save archives are seeded with the opening checkpoint if it is missing, while keeping the current active checkpoint selected, so the opening is always available as the leftmost save for quick testing. The maintenance shutter at x=-1100 is partially raised, exposing the existing forest. The warning lights and alarm begin at the opening and fade as the robot gets farther from the factory. Fence fragments at x=-830 through -160 leave a pedestrian gap. Walking to x=-200 automatically advances the checkpoint to the existing forest; the water gate and inner-yard sentry follow, with the police search now outside the prison wall.

The alarmed factory start reuses the existing `reclamation` save slot; `factory-escape` adds a second safe record after the stampede. Both use the existing version-1 save format. Older saves remain valid: loading an old reclamation record now reopens the new start, while forest/sluice/far-bank records retain their positions. The former P/T replay shortcuts have been removed. The station exit keeps its own automatic safe checkpoint. Esc opens Continue / Load saves; opening the game resumes automatically. See `autosave.md`.

The first art pass uses Cocos Graphics for station architecture, conveyor, shutter, fence and lamp, plus the existing robot atlas for the fleeing copies and darkened inactive robots. Audio sources: `design/generate_reclamation_audio.py`, producing machinery and alarm WAV loops using only the Python standard library. Audio is gesture-unlocked, distance-mixed and stopped on component destruction.

Validation: TypeScript checking and 27 tests pass. New tests cover fresh start, traversal at 30/60/144 FPS, checkpoint persistence, left boundary and compatibility with old forest saves. Live Cocos browser preview was used to walk from the holding area through the maintenance door and fence into the forest, then return to the opening via the touch replay label. Sound mixing and mobile device behavior still need listening/device review. The browser is left at the holding area for user review.
