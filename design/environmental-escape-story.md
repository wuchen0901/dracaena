# 环境叙事新方案：逆向逃出处理人的工厂

状态：故事重设计初稿。记录本轮讨论的新方向与候选场景，尚未完成与现有关卡的逐段对接。

## 重设计方向

放下旧故事的因果框架，保留现有逃命环节，通过补充场景重新建立故事。暂不承担装灯职业、灯泡与星星的关系、老人故意吸引主角等解释任务。

主角的眼前目标始终是逃出去。沿途的环境逐步揭示这里对人做了什么。抓捕、迫害和追逐直接构成逃跑理由，不要求玩家先理解世界背景或主角身世。

主角是行动上的参与者，可以对世界的整体真相了解有限。玩家必须看懂当前危险和行动目的；统治者身份、技术原理、外界是否知情可以留白。

## 候选故事设定

一座封闭工厂把抓来的人变成失去自主性的劳动工具。失去劳动能力的人会被送去焚烧。主角在运送“废弃人员”的车上醒来，因为还活着而开始逃亡。

“僵尸”暂定为仍然具有人类外表、却只服从信号的劳动者，不必采用感染或亡者复活设定。他们不再逃跑，与仍会恐惧、挣扎的普通人形成可见差异。

工厂处理人的顺序：

**抓捕 → 关押 → 剥夺自主性 → 强制劳动 → 倒下并被运走 → 焚化。**

玩家大体沿相反方向逃离：先看到结果，再看到受害者此前的处境，最后发现他们原本也和自己一样。

以下流程是候选故事骨架，不代表已经实现的关卡顺序。

## 场景递进

### 1. 焚化炉：我必须离开这里

主角在堆着人体的运输车里醒来。车正在缓慢接近炉口，工作人员把垂下的手脚推回车内。玩家爬出车，躲过工作人员，从设备下方逃走。

玩家首先理解：这些身体正在被送进炉子，自己也在其中，被发现会有生命危险。

此处只需露出少量身体，暂不展示全部规模。动作重点是醒来、察觉危险和逃离，不补充复杂身世。

### 2. 尸体分拣区：这件事每天都在发生

玩家来到焚化炉的上游，看见成批运输车、集中收走的衣物和假肢，以及不断运来的身体。工作人员清理车厢、回收衣物、等待下一批。

新增信息是处理流程的常态化，而不只是尸体数量增加。这里不是一次偶然的杀人事件。

机械躲避、传送带和狭窄通道等玩法可以与此区域结合；具体复用哪些现有环节，需要后续核对。

### 3. 活人暂存区：他们连活人也送去处理

隔间里有人伸手求助，有人听到运输车就退向墙角。工作人员到来时，所有人突然安静。一个不愿上车的人被拖走，躲在附近的主角可能因暴露而遭到追捕。

玩家理解：这些人知道接下来会发生什么，被送去焚化的人不一定已经死亡。

迫害事件应有清楚的可见过程，让追逐成为场景事件的后果。无需靠文字宣布这里很危险。

### 4. 劳动作业区：原来他们此前被这样使用

巨大的生产空间里，成排的人重复动作。铃声响起，他们同时停下；指示灯变化，他们同时转身。一个人倒下，其他人继续工作。工作人员把倒下的人拖进前面出现过的同型运输车。

运输车是连接前后因果的关键线索：玩家能够辨认这些劳动者最终会被送去哪里。

这里出现所谓的“僵尸”。他们仍像人，却不再主动躲避危险或尝试逃跑。主角可以混入队伍，模仿动作躲避巡查；行为不同而被识破后，可接入逃亡段落。

### 5. 监狱与接收区：他们原本也是普通人

接近出口时，玩家看见刚被抓来的人。他们穿着不同的衣服，会挣扎、互相拉住、尝试逃跑。随后他们被分开，换上统一衣物，带往工厂内部。

通过相同制服、相同路线和重复出现的设施，把普通囚犯与此前的劳动者联系起来。若试玩时这层关联仍不清楚，再补充可见的转变过程，不能默认玩家会自行猜中。

此时玩家应能拼出“被抓来的普通人—劳动者—被运走的身体—焚化炉”这条链，理解自己正在逃离的共同命运。

### 6. 出口：以具体的逃离行动结束

基础结局：下一批囚犯被运入时，主角利用外门开启的机会逃出去。

可选变化：逃离路线经过囚车锁扣，主角可以放出其中几个人。这个局部行动能够体现参与，不必突然赋予主角摧毁整座工厂的使命。是否加入救人及其交互方式，留待关卡设计确定。

## 环境叙事的层次

| 区域 | 玩家获得的新认识 |
| --- | --- |
| 焚化炉 | 我正在被送去烧掉，必须逃走。 |
| 分拣区 | 这里长期、大规模地处理人的身体。 |
| 活人暂存区 | 活着的人也会被送去处理。 |
| 劳动作业区 | 人被当成劳动工具，倒下后进入处理流程。 |
| 监狱与接收区 | 这些劳动者原本是被抓来的普通人。 |
| 出口 | 我逃出了这套流程，其他人仍在被送入。 |

每个区域都增加一条关系或改变一次理解，避免把炉子、尸体、活人、僵尸和监狱做成互不相关的恐怖陈列。重复的运输车、制服和路线用于建立因果，而非依靠额外说明。

## 后续对接原则

- 保留现有逃命玩法，先梳理其顺序、触发原因和结束位置，再决定新增场景插在哪里。
- 让追捕来自可见的威胁，例如被看守发现、逃离押送或混入队伍后暴露。
- 区分玩家能看到的证据与作者脑中的设定。尤其是“普通人被变成劳动者”，需要场景实际支持。
- 不要求每个背景谜团都得到答案，但必须让玩家理解主角为何继续逃跑。
- 本文件独立保存新方案；旧设计文档留作参考，尚未在此轮统一改写。
