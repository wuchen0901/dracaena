# 路途角色与野生动物（第一版）

这些角色先作为地图中的环境人物出现，不加入商店、任务或专用操作。人物采用低饱和色块和清晰剪影，和现有的程序绘制场景保持一致；鸟群与野猫带少量循环动作。位置为世界横坐标，后续可以随地图调整。

| 位置 | 角色 | 外形识别点 | 场景作用 |
| ---: | --- | --- | --- |
| 8580 | 流浪者「背苗人」 | 旧绿背包、斜背行囊、随身小苗 | 在废城边缘继续迁徙，也把生命带在身边 |
| 9310 | 摊贩「旧物商」 | 破布遮棚、低矮摊台、分拣好的旧零件 | 展示物品价值因人而异，不设货币或任务菜单 |
| 10710 | 野猫「瘦尾」 | 栖在矮墙上，灰褐色、尾巴微动 | 保持距离，作为独立生活的动物出现 |
| 11610 | 算命者「看信号的人」 | 旧斗篷、裂镜、三枚小圆片与垂落线路 | 通过残存传感器猜测未来，暗示预测并不等于理解 |
| 13920 | 卖唱者「拾音人」 | 长外套、拼装弦乐器，偶有暖色音点 | 让废墟保留声音和记忆 |
| 8780、12460、16180 | 鸟群「灰翅」 | 三处不同高度的小群鸟，轻微振翅 | 随路线从城市边缘延伸到野地，显示生命正在回归 |

所有人物都可以被玩家看见，但当前只负责构成世界，不阻挡路线，也不改变存档或谜题状态。后续可再决定是否为个别人物增加互动。
