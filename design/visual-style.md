# 画面风格：雾里的剪影

这份文档记的是在第 21 章“墙”（`Last/sidescroller/src/69-ch14-wall.js`）里一步步试出来的画面做法。那一章是试验关：一堵从镜头跟前伸到看不见的地方去的旧砖墙，孩子跳一下翻过去。之后别的章节要做成同样的感觉，照这里来。

## 一句话

**光只给孩子周围；近处没有理由地黑；远处被浅灰的雾抬亮、吞掉；颜色几乎全去掉，只在几样小东西上留一点。**

## 原则

### 1. 近处黑，就是因为不打光，不需要理由

画面要哪里黑，哪里就黑。不要为了“近处为什么暗”去找理由：路灯加挡光板、爬藤、镜头后面放一排挡光的废楼、把月亮挪到背后逆光，这些都试过，都是绕远路，最后都拆掉了。

- 从孩子脚下往镜头方向，两米之内压到纯黑。
- 光只照孩子周围两三米，并且跟着孩子走。
- 远处另算（见第 3 条）。

### 2. 暗下去的边不能是一条直线

在平地上按距离压暗，画面里就是一条横线，非常假。解决办法是：

- **地面要有起伏**：土包、凹坑、尖棱，越靠镜头起伏越大。
- **明暗跟着地形走**：鼓起来的地方多接一点光，凹下去的先黑。
- **边要蜿蜒**：用一层大尺度的噪声，让暗的边左右拐弯。

### 3. 雾是浅灰的：越远越亮、越看不清

- 远处的东西被雾抬成灰色，近处没有雾，所以显得最黑。
- 远处同样看不清，细节都被雾吞掉，玩家不会一眼望到头。
- 中景放几层剪影（枯树、断柱），一层比一层浅，层次就出来了。
- 远处的地面要越远越高（丘陵、岩脊）。它们在孩子身后，不会挡人；还能挡掉更远的一截，多出一层。

### 4. 颜色几乎去掉，只在小东西上留一点

- 雾、远景、山：全灰。
- 地面、墙：留一半左右的颜色。
- 小东西留颜色：黄色、褐色的落叶，褐色的树枝，石头上的一丝青苔绿。
- 孩子是画面里最亮、最显眼的。
- 只有黑白灰太闷；小东西上的一点颜色区别，让画面活起来。

### 5. 近处做细，远处只要轮廓

- 近处的东西要经得起看：砖有倒角，砖缝缩进去，砖面有颗粒、小坑、雨痕；岩面有岩层、石缝、地衣、积水。
- 远处换成粗的大块，细节交给着色器画，反正会被雾和暗吞掉。
- 地面纹理（裂纹、斑点、砂粒）按离镜头的距离淡出，远处不闪。

### 6. 路不是一条直线：前后会弯，高低会起伏

- **前后弯**：玩法上一直往右走，但画面里的路会往镜头这边靠一点、往远处去一点（这一章是前后各约 3 米）。
- **镜头要追**：镜头在前后方向上追着孩子走，慢一拍，人的大小基本不变。不能让人不自然地变大变小。
- **路本身也要起伏**：只让路两边起伏、路中间一条平带，看起来就是人工压出来的路，很假。物理地形按同一个高度登记，孩子真的在上坡下坡。
- **细碎的小起伏不要放在脚下**：只放在路两边，否则脚会一会儿陷进去、一会儿浮起来。

### 7. 前景：放什么都要矮于视线，并且不要抢眼

- 前景的废料、柱子这些试过好几版。最后在这一章是去掉前景道具，直接让近处的地面沉进黑里，效果最干净。
- 如果以后要放前景：
  - 它们本身要平、暗，只剩轮廓；
  - 高度要矮于“镜头看孩子脚”的那条视线，不能挡住人；
  - 镜头这一侧的地面不能鼓起来，否则会把整个画面挡黑。

## 试过、但不要再用的

| 做法 | 问题 |
|---|---|
| 远处一律压暗成黑 | 太闷；改成浅灰的雾以后好得多 |
| 画出来的草、画出来的树林 | 一眼就能看出是画的；远处只留雾里的剪影 |
| 路灯 | 每个场景都要立灯，太受限；光不需要理由 |
| 前景靠影子变暗（挡光板、爬藤、镜头后的废楼） | 绕远路；要么边很硬，要么到处漏光 |
| 墙塌掉一截来露出前景 | 墙塌了，玩家还去翻，显得很傻 |
| 镜头只跟弯路的三成 | 孩子会不自然地变小 |
| 镜头越过墙 | 伸到镜头跟前的那段墙会挡住人；靠近墙时镜头要留在孩子这一侧 |

## 在代码里怎么做（第 21 章）

- **`wallD(q, hy)`（着色器）**：这一章的“光的分配”，决定天光和月光在每一处还剩多少。它管孩子周围的光圈、往镜头这边压黑、远处的衰减、云缝里漏下的几块月光。灯（聚光灯、点光源）不受它管。
- **`shade(mat, kind, sat)`**：给材质套上这一章的着色。`kind` 管表面是什么（砖、远处的整条墙、地面、其它），`sat` 管留多少颜色。
- **地面高度**：
  - `BIG`：大起伏，连路一起，物理地形按它登记；
  - `BIGG`：镜头一侧不许高过路；
  - `DET`：细起伏，只在路两边，存进顶点属性 `aDet`，着色器用它做“高处多接光、凹处先黑”。
- **公共代码**：
  - `zpath(x1, x2, f)` 和 `pathZ(x)`（`20-world.js`）：路往前后弯。主角放到弯路上，并顺着路转身；镜头用 `cam.pz` 慢一拍追过去（`90-main.js`）。没登记的地方是直的，所以其他章节不受影响。
  - `camOvr.lift`：章节接管镜头时也能压低镜头。
- **镜头高度**：压到孩子眼睛的高度，墙才看得出是墙，不像一条路。

## 套用到第十八章「夜搜」（2026-11-16）

直升机那一章照上面七条重做了画面（`Last/sidescroller/src/69-ch11-heli.js`、`69-ch11-art.js`；前后对比 `generated_images/heli-search-fog-before-after.jpg`）。和第 21 章不一样、要另外处理的地方：

- **探照灯不受“光的分配”管**：和第 21 章一样，`lite11` 只压天光和月光，聚光灯、点光源照样亮。灯扫到哪里，哪里就亮；画面里最亮的东西还是那盏灯，孩子靠红上衣和身边那一圈光认出来。
- **镜头离得远（二三十米），雾不能只靠场景的雾**：场景的雾按“离镜头多远”算，浓到能吞掉远处时，孩子自己也被蒙住了。这一章的雾在着色器里按“离路多远”算（`haze11`），场景的雾只留很淡一层；贴地的雾浓、高处淡，所以天上那几架直升机还看得出影子，只是越远越淡，远处几架主要剩灯。
- **雾里的剪影换成立体的**：原来画在布景板上的林线、山、高压线塔、谷仓和水塔都拿掉，换成几层立体的枯树、一座塌了半边的谷仓、一座水塔、四座高压线塔，全靠雾一层层抬浅。过了断桥的林子也是一排排枯树干，越往里越密。
- **没有为明暗找理由的灯**：路口的路灯（连同绕着它的飞蛾）、断桥底下“漏进去的天光”都拿掉了。躲在顶下面时孩子的轮廓光（`HERO_RIM`）亮一点，不然桥底下整个人看不见。
- **前景**：路前面不种草、不放东西；原来躺在路前面的塌桥板、集装箱掉下来的侧板拿掉了；路牌挪到路的另一边。暗下去的边：路沿外一溜不高于路面的小土包接一点光，再加一层沿着路的大尺度噪声，边就不是一条横线。
- **地面自己铺**：路面那一条是平的、和物理地形分毫不差（路面贴图按地形折点切）；电线杆、铁丝网那一溜也平（杆上歇着乌鸦）；再往后的野地越远越高。远处那块比这一章宽得多，而且总比共用的地面高一点，盖住它。地面按 x 切成一条条，镜头外的不画。
- **没做的一条**：路的前后弯、高低起伏（第 6 条）。四处掩体、光柱在屋顶下的裁剪面、乌鸦、路面的标线都是按一条直的、平的公路摆的，要弯、要起伏得一起挪，玩法上也要重新验，留作单独的一步。
- **代码**：`lite11` / `haze11` / `shade11`（受光的材质）/ `hazeOnly`（不受光的，比如旋翼的虚影）/ `DET`、`gy`（地面起伏）都在 `69-ch11-heli.js` 开头；`deadTree`、`pylon`、`fogRockGeo`（第 21 章 `rockS` 的一份拷贝，第 21 章自己那份没动）在 `69-ch11-art.js`。

## 套用到《逃出工厂》第 7 章「雾」（2026-11-16）

加“雾”这一章（`Last/sidescroller/escape/68-e8-fog.js`）时整章照这里做；章节号从这一天起往后挪了一位：“墙”现在是第 22 章，“夜搜”是第 19 章（上面写的“第 21 章”“第十八章”是当时的编号）。和“夜搜”不一样的地方：

- **路会前后弯**：着色器里的“离路多远”都按弯路算（`pzf`），地面的起伏、暗下去的边、雾都跟着路走。
- **雾更浓、镜头更近**（十五米上下）：十米开外的看守只剩影子，灯照到的才亮。人（看守和那个逃出来的人）也走这一章的明暗和雾。
- **手电不受“光的分配”管**：离主角最近的那一盏是真的带影子的灯，其余几盏只画光柱、灯头和地上的亮斑。
- **邻章的布景板**：大门那一章和结尾画在布景板上的远景在雾里是一块块发蓝的画；镜头在这一章里时把它们淡掉，出了雾再淡回来（`fadeBoards`）。
