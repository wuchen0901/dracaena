# 工厂深处（第 25–36 章）

更新：2026-11-16。十二个恐怖工厂的场景，每个做成一章灰模，先看这些画面和规矩成不成立。源码在 `Last/sidescroller/src/69-h00-kit.js` 和 `69-h01` … `69-h12`，怎么走、怎么查过的见 README 的“工厂深处”一节。

## 讲法

照《逃出工厂》的规矩来（`environmental-escape-story.md` 第二节，2026-11-19 删了，在 git 历史里）：

- 只讲看得见的东西，没有对白，没有带字的招牌。只留操作提示。
- 远看能认的只有剪影、颜色和光。液体都做成单一的颜色、自己发光，场景再暗它也是最亮的东西，人站在前面就成了剪影。
- 先看到结果，再看到原因：地上的蚀痕（第 31 章）、漂着的白色内衣（第 26 章）、捅下来的那个人（第 32 章）。
- 过关的办法尽量是“像这里的东西一样动”：在漂浮物上装成一团东西（第 26 章），挂进工服里跟着晃（第 32 章），躺在货里（第 33 章），安静的时候和冷库一起不出声（第 34 章）。

## 还没做 / 没定的

- 这一组现在单独排在旧原型和试验关后面（第 25–36 章），没有放进《逃出工厂》的路线里。哪几个要并进故事、放在哪一章前后，还要定。
- 造型都是灰模：方块、圆柱、共用的“小人”。液体的着色器、泡、雾是正式的路子，颜色还可以再调。
- 声音只用了现有的合成音（铃、咕嘟、嘶嘶、碎玻璃），没有单独录的，也没在耳机里听过。
- 第 29 章的液面涨速（每秒 0.2 米）是按自动玩家的速度留了一倍多的余量定的，真人玩起来可能还要再慢一点。
- 第 27 章转桥的时间窗口（对齐前后各 1.7 秒）和第 31 章的滴液节奏，没有真人试过难不难。
