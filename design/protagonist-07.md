## 一句话

一台量产的、没有脸的旧劳动机器人；全身唯一的暖色，是胸口那盏代表剩余能量的灯 —— 它就是标题里的“最后的光”。

向 INSIDE 学的是方法（远镜头、无脸、一个强调色、靠动作演戏），不是造型。“人类小孩 + 一块鲜艳的上衣”是那个游戏自己的标志，照着做只会像仿制品；07 的强调色来自我们自己的故事。

## 之前的版本卡在哪

1. **在摄影棚里设计，却在侧面远镜头里玩。** V1–V5 和几张概念图都是正面或斜侧面的近景。游戏镜头是纯侧面，角色只占画面高度的 12–17%。V5 从侧面看只剩“一个盒子插在杆上”，看不出朝向。
2. **细节太多，形状太少。** 斗篷、围巾、藤蔓、提灯、铆钉、划痕，在一百来个像素高的角色身上全部消失，剩下的轮廓反而是糊的。
3. **没有明度和颜色的计划。** 象牙白、灰蓝、橄榄绿、锈红同时出现，没有哪一块是“眼睛应该落在这里”。
4. **可爱的眼睛和这个世界冲突。** 两只圆眼睛是玩具的语言；冷、暗、沉默的世界里，主角越没有表情，玩家越会把自己放进去。
5. **和故事没有扣上。** 三个人类小孩读得很清楚，但换进任何一个末世游戏都成立。剧本写的是编号 07 的劳动机器人、同型号被成批回收、最后要决定把最后的能源给谁 —— 主角的造型应该只属于这个故事。
6. **候选太多，没有淘汰标准。** 所以先定下面三条检查，以后任何新造型都先过这三条。

## 三条检查

- **剪影**：涂成纯黑、缩到 100 像素高，仍然看得出朝向、姿态，而且认得出是它。
- **无脸**：不画眼睛和表情。情绪交给姿势和那盏灯。
- **一个强调色**：整个画面里只有它的灯是暖色。身体、环境、其他机器人都不许抢。

## 造型

| 部位 | 做法 | 为什么 |
| --- | --- | --- |
| 头 | 圆顶“桶”形头盔，帽檐只往前伸；帽檐下是一整块深色面罩，没有眼睛 | 帽檐让侧面一眼看出朝向，也让转头看得见；安全帽说明它是工人；脸是一块黑，不是一张表情 |
| 躯干 | 上宽下窄，胸口微鼓，背上隆起一块电池舱，顶上一只吊环 | 侧面是个弓着背的小工人；吊环是回收线把同型号一台台吊走的地方；电池舱对应剧本里的电池选择 |
| 灯 | 胸口正中一颗凸出来的琥珀色指示灯 | 凸出来，所以从侧面也看得见；位置是“心口” |
| 四肢 | 细，关节只露一道深色的缝；小臂和小腿往末端变粗，深色的手，厚底靴 | 像戴着大一号手套、穿着大一号靴子的孩子；摆动时末端有重量感 |
| 编号 | 头盔两侧喷“07” | 玩的时候只是一小块深色，按 V 拉近才看得清；它是产品，不是角色定制 |

比例（`u` = 身高单位，1.24 m）：髋高 0.46u，大腿和小腿各 0.205u，肩到髋 0.255u，上臂 0.17u，小臂 0.155u，头高约 0.19u。腿略短于身高的一半、头约占五分之一、手垂到大腿中段 —— 孩子的比例。髋高比腿长略短，所以它站着时膝盖总是微微弯着。

颜色只有三个明度，加一盏灯：

| 用途 | 颜色 | 说明 |
| --- | --- | --- |
| 外壳 | `#85988b` | 旧机床的灰绿。带 22% 自发光，暗处不会掉到看不清，强光下也不发白 |
| 检修盖、靴子 | `#5c6c62` | 深一号 |
| 关节、手、面罩、鞋底 | `#1b1f20` / `#08090a` / `#121415` | 近乎黑 |
| 灯 | `#ffc67e`（亮）→ `#6e3410`（暗） | 全身唯一的暖色 |

## 灯就是它的表情

| 状态 | 灯的表现 |
| --- | --- |
| 站着 | 跟着呼吸一明一暗 |
| 任何时候 | 每隔几秒电压不稳，闪两下（它老了） |
| 走、跑 | 光落在身前的地上；手臂扫过灯前时被照亮、又把灯挡住 |
| 推车、靠近东西 | 照亮手里和面前的东西 |
| 从高处落地 | 被震得一暗；普通跳跃只轻轻晃一下 |
| 躲在矮墙影子里、探照灯扫近 | 弓起身子，双手拢在胸口捂住灯，光只从指缝漏出一点 |
| 被探照灯盯上 | 慌乱地快闪 |

这些目前都只是表现，**灯还不影响是否被发现**。

## 文件和调参

- `Last/sidescroller/src/40-character-build.js`：`buildRobot07()` 是造型；`profileShape` / `slab` 把一圈侧面轮廓挤成实体，改躯干、靴子的形状只要改那几个轮廓点。颜色在 `M`，比例在 `D`。旧版小机器人保留为 `buildOldRobot()`，只为对比。
- `Last/sidescroller/src/42-character-anim.js`：`A.cover` 是捂灯的姿势，文件末尾 `if (Lm)` 那一段是灯的全部行为。
- `Last/sidescroller/src/60-ch1-factory.js`：`HX.hide` 决定什么时候捂灯（现在是：在矮墙影子里、光束在 4–8 米内、基本站住）。各章节每帧往 `HX` 里写 `hide` / `alert` / `energy` / `pose`，由 `90-main.js` 交给主角动画。
- 改完运行 `bash Last/sidescroller/build.sh` 重新生成 `Last/sidescroller.html`。
- 在浏览器控制台里可以直接试颜色：`__g.hero().B.M.shell.color.setHex(0x85988b)`（自发光色是 `.emissive`）。
