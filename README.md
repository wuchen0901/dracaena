# The Last Light

一个横版解谜冒险的原型。代码全部在 `Last/` 里，用 three.js 写成，直接在浏览器里运行。

页面只有一份：`Last/escape.html`（2026-11-15 把原来单独的旧原型页面 `sidescroller.html` 并了进来），一共二十二章，排成一条路：

- 第 1–8 章：新故事《逃出工厂》的灰模（七章加结尾），见下面“《逃出工厂》故事灰模”。原来的第一章“焚化炉”2026-11-15 删掉了，游戏从“分拣”开始；2026-11-16 在“大门”和“结尾”中间加了一章“雾”（第 7 章），结尾成了第 8 章。
- 第 9–22 章：旧原型《铁锈与微光》的十四章，旧的第 k 章现在是第 k + 8 章（加“雾”以前是 k + 7，2026-11-16 以前的提交说明、设计文档里的章节号是那时候的）。其中旧第九章“山洞与暗河”（现第十七章）是 2026-11-13 新加的、要游泳的一段长山洞；旧第十章“吊绳与高台”（现第十八章）是同一天新加的、要跳起来抓住绳子往上爬的一段大台阶；旧第十一章“夜搜”（现第十九章）是 2026-11-14 新加的：夜里一架直升机用探照灯沿着公路找主角，要一处一处躲过去，等它飞走。故事还在重写，这三章先单独放在最后，从章节菜单进。旧第十二、十三章（现第二十、二十一章）是《长夜》的原型 C（机房与选择），见下面“《长夜》原型 C”。旧第十四章“墙”（现第二十二章）是 2026-11-16 试画面风格的一关，见 `design/visual-style.md`。

- 第 21 章“墙”（`src/69-ch14-wall.js`，旧编号 14，`?ch=21`）：试画面的一关（近处做细、远处压暗，雾里的剪影），接在旧原型后面。先是一道跳一下就翻过去的矮砖墙；2026-11-16 在它右边加了一个小关卡 —— 第二道墙有两米高，跳起来够不着，要按住 E 把左边那只旧木箱沿着地上的拖痕推到墙脚，跳上箱子，再朝墙头跳，翻过去。箱子的高度正好是两道墙的高差，所以从箱子上翻墙用的还是翻矮墙的那一段动作；这一段路是平的、直的（箱子只能在平地上推）。

下面各节说到旧原型的“第几章”、源码文件名里的数字（`69-ch11-heli.js` 之类），都还是旧的编号；说到《逃出工厂》的“第几章”、`escape/` 里的文件名（`62-e2-sorting.js` 之类），都还是故事文档里原来的编号（文档里的第二章“分拣”是游戏的第 1 章）。

仓库根目录原来还有一个 Cocos Creator 3.8.8 项目，已在 2026-11-12 删除。需要时可以从 git 历史找回，最后一个包含它的提交是 `01addf2`。

## 运行

```bash
python3 -m http.server 8765 --bind 127.0.0.1 --directory Last
```

然后在浏览器打开 <http://127.0.0.1:8765/escape.html>。页面需要联网，three.js 从 cdn.jsdelivr.net 加载。

没有装 Python 的机器（比如 Windows）用 `node Last/tools/serve.mjs 8765` 代替上面那一行，`.claude/launch.json` 里对应的是 `last-prototype-node`（端口 8771）。

地址后面加 `?ch=4` 可以直接从第四章开始，`?ch=7` 是新加的“雾”，`?ch=9` 是旧原型的开头（工厂），`?ch=17` 直接进山洞，`?ch=18` 直接到吊绳那一章，`?ch=19` 直接到直升机搜人的那一章，`?ch=20` 从凿记号开始玩《长夜》原型 C，`?ch=21` 直接进机房（灯泡已经在包里），`?ch=22` 是“墙”。按 Esc 选章节：左边一列是《逃出工厂》，右边一列是旧原型。

## 《逃出工厂》故事灰模

新故事（`design/environmental-escape-story.md`）2026-11-15 做了一版灰模，原来是七章加结尾；同一天把第一章“焚化炉”删掉了；2026-11-16 在大门后面加了一章“雾”。现在七章加结尾，是游戏的第 1–8 章，直接打开页面就从“分拣”开始：

<http://127.0.0.1:8765/escape.html>

地址后面加 `?ch=4` 直接从第四章开始（1 到 7 是七章，8 是结尾）；按 Esc 也能选章节。存档是 `escape-factory-save-v3`，所有章节共用一份（加了“雾”以后后面的章节号都挪了一位，`v2` 对不上了；更早的 `escape-factory-save-v1` 和旧原型单独那份 `rust-glimmer-save-v1` 也不再读）。

- 第 7 章“雾”（`escape/68-e8-fog.js`，2026-11-16 加的）：出了林子，路往山上去，起了雾。看守打着手电从山下一个一个跟上来，在雾里往下照。规矩是**光照到身上时站住别动**（雾里只看得见动的东西）；在光里走、跑、跳就被盯上，盯满了回到存档点。路上要跳过一棵倒树、一道干砌石墙。半路上石头后面蹲着另一个逃出来的人：灯一扫到他，他跳起来就跑，几盏灯一齐落到他身上，他举手，被两个看守押下山去（第 6 章拉开过囚车的锁扣，他的衣服颜色和那时跑掉的人对得上）。画面照 `design/visual-style.md`（着色是从“夜搜”那一章抄过来、改成跟着一条前后弯的路）。两头邻章画在布景板上的远景在雾里是一块块发蓝的画，镜头在这一章里时把它们淡掉。`Last/tools/fog-route.html` 是这一章沿路的画面和自动玩家的检查（`?layout=route` / `check`）。

- 删掉焚化炉：那一章的源码 `escape/61-e1-furnace.js` 删了（git 历史里还在）。它搭的几样东西搬到了“分拣”（`62-e2-sorting.js`）：地形的起点、左边那道墙（原来留门洞通焚化炉，现在封死）、挡着往左走的墙、教“← → 移动”的提示。后面几章布景的随机数种子、人物的随机数都照删以前的接着算（`src/20-world.js` 的 `origN`、`62-e2-sorting.js` 开头的 `_figSeed`），位置、存档点、碰撞、每个人的长相都和删以前一样（对照提交过的页面查过）。开场“在推车上醒来”没有了，第六章（接收）“打倒扔上车”要让玩家想起开场的那一层现在没有铺垫。公共部分为它加的 `pose.lie`（仰面躺着）现在没有章节用。
- 灰模的意思：先看故事的顺序、每一章的规矩走不走得通。人物是一套简单的小人，场景是方块和剪影，造型都没定；每一章比文稿估的短，整个走一遍十几分钟。
- 多出来的两个按键：按住 `Shift` 慢走（游戏第 1 章跟推车、第 3 章跟队伍、第 4 章在检修道上都要用）；按 `C` 换主角自己衣服的颜色（蓝 / 砖红 / 土黄 / 绿，故事文档里这一条还没定，先放着对比）。
- 每一章做了什么、和文稿不一样的地方，记在故事文档的第十一节。
- 源码：公共的部分还是 `Last/sidescroller/src/`（核心、角色、玩家、声音、界面），这几章在 `Last/sidescroller/escape/`。`bash Last/sidescroller/build.sh` 把它们和旧原型的十四章拼成一份 `escape.html`。两段在世界里不重叠：旧原型还在原来的位置（从 x = -60 起），《逃出工厂》整段挪到它左边（`escape/60-kit.js` 的 `EX`，中间空出一千来米；删掉的焚化炉原来在 `EX - 60` 到 `EX + 80`，那一段空着）；旧原型的章节号写成 `OLD + 旧编号`（`src/20-world.js`，`OLD` 现在是 8）。挪位置、改编号时留意过的几件事：章节要按从左到右的顺序登记（地形、光的关键帧都按登记的先后接起来）；每章布景的随机种子按它原来的编号算（`origN`：旧原型是自己的编号，《逃出工厂》是删掉焚化炉以前的编号，后加的“雾”是 15），样子不变；光的关键帧会沿用上一个，旧原型的第一个从默认值算起（`env(…, true)`）；每次 `ceiling()` 是单独一段洞顶；照世界 x 算的花样（远山的山脊线）用 `ex(x)` 换回挪之前的 x；《逃出工厂》载入时用掉的关卡随机数，载完拨回去（`ESC_SEED`）。
- `escape/60-kit.js` 是这几章共用的东西：路上的人（每种身体零件一个实例化的网格，几十个人只多十来次绘制）、推车、铁栏杆、卡车、手电和探照灯“盯住人”的规矩、厂房的墙和布景。
- 为它在公共部分加的几处：`42-character-anim.js` 的 `pose.lie`（仰面躺着，开场用）；`40-character-build.js` 的 `HERO_TOP`（主角上衣在着色器里换色，只在第 1–8 章）；`52-audio.js` 的 `AUD.wheels`；`80-ui.js` 里章节可以自己写结局画面上的字（章节的 `end`）。旧原型的章节里这些都不起作用。
- 没做的：只在电脑上用自动玩家跑过，没有在手机上量帧数；声音只加了铃、炉口的火和几下闷响；旧的十三章没有拆。

## 《长夜》原型 C

> 2026-11-15：《长夜》方案已废弃，故事换成 `design/environmental-escape-story.md`（《逃出工厂》）。这一段原型的代码还在，留作参考；下面提到的 `long-night-story.md` 已删除，可在 git 历史里查看。

`design/long-night-story.md` 第九节要先做三个短片段再重排十章，并建议先做 C（机房与选择）。2026-11-14 做了这一段，灰模，先验证信息的顺序：

- 第十二章“作坊一角”：开头垫的十几秒。按三次 E —— 修灯、在灯头的金属套上凿出缺了一角的方框（镜头推近）、取下来只剩余光；举到检验光底下骤亮一下，筐里的坏灯不亮；用布包好收进斜挎包。从右边的门出去，黑一下就到机房门口（中间九章还没做）。
- 第十三章“机房”：一屏宽，老人一直坐在里面。三道闸刀依次合上：小窗（按住检修柄往下带，白光进来，包里的灯泡透出光，备用灯泡一齐亮，老人那只旧灯不亮）→ 控制台（屏幕一块块亮出侧窗、钟表街、断桥和巡逻图；在检修位的空灯座下按 E 取出灯泡对一下）→ 星灯回路（另一处故障跳起来，老人伸手够调整杆停在半路，孩子把接点按回去）。站到老人桌前、挂着的衣服前，镜头会推近。最后两件装置都是按住到底才算数，中途松手原样退回，后半程更慢更重：空灯座（拧回去）、右墙边的应急开罩手柄（拉闸）。结局后面不写结局名，按 R 回到选择之前。
- 新的“按住型机关”（`50-player.js` 的 `holdable`）：键盘按住 E，触屏长按、手指不松就一直按着；新按一下才开始，一直按着 E 走过去不算。
- 灯泡和斜挎包在 `43-carry.js`：灯泡灯头朝上，记号是凿穿金属套的镂空（亮着是亮的形状，暗着是黑的缺口）；包是灰模占位，样子还没定（故事文档第十节第 10 条）。取出、收回的手势也在这里；主角模型上“手放到哪一点”的反向运动学是 `42-character-anim.js` 里新加的 `pose.hands`。
- 还没做的：A（落星开场）、B（巷子维修，星空从着色器变成数据）、十章重排和夜景（要先定假天空里有没有月亮）、存档换成新故事。

主角不总是正侧面：站着是四分之三侧身，隔几秒换一个站法（有时背过身去看远处）；走、跑、跳时身子朝镜头转过来一点，肩和胯反着拧；原地转身时脚跟着挪步；推拉、攀爬、摆好的姿势还是正侧面。数值在 `42-character-anim.js` 的 `TURN` 里，地址后面加 `?turn=0` 回到原来的正侧面（对比用）。

在手机上看：用 `.claude/launch.json` 里的 `last-prototype-lan`（端口 8770，同一个 Wi-Fi 里的设备都能打开），手机上打开 `http://<这台电脑的局域网地址>:8770/escape.html`。`tools/phone-check.html` 在手机上量帧率、查柔边能不能用，结果记进服务器日志。

## 操作

| 按键 | 作用 |
| --- | --- |
| ← → 或 A D | 移动 |
| 空格 | 跳跃、攀爬；在水里往上游；跳起来手碰到挂着的绳子就抓住 |
| ↑ 或 W | 跳跃；抓着绳子时往上爬 |
| ↓ 或 S | 在水里潜下去；抓着绳子时往下滑，滑到头再按住就松手 |
| E | 按住推拉，按一下操作机关；机房的检修柄、拧灯、拉闸要一直按住 |
| Shift | 慢走 |
| Esc | 选择章节 |
| R | 回到存档点 |
| V | 近看主角 |
| M | 静音 |

## 目录

- `Last/sidescroller/src/`：原型的源码，按文件名顺序分段（核心、世界、布景、灯光、角色、地上的东西、玩家、声音、八个章节、空中的细节、界面、主循环）。`47-cave-kit.js` 是山洞的布景套件（岩石的剖面、后墙、水色、水面的亮线、光柱、焦散），`68-ch9-cave.js` 是第九章，`74-water-fx.js` 是水里的气泡、水花和波纹；游泳的操作在 `50-player.js` 最后一段，游泳的动作在 `42-character-anim.js`。`51-rope.js` 是绳子：挂着的绳子（一串小段，被风吹着、被人抓着时跟着人摆）、抓住 / 往上爬 / 往下滑 / 翻上旁边的台阶，以及把主角模型的两只手、两只脚摆到绳子上；`69-ch10-ropes.js` 是第十章。`46-ground.js` 是各章共用的地上的东西：石头、落叶、草和蕨（一张共用的图集）、树枝和倒木、泥、会映出画面的水洼，还有走近了会逃开的青蛙、蜥蜴和虫子。空中的细节在 `70-air.js`（光里的尘埃、落叶、风沙、虫子、远处的鸟群、萤火虫）、`71-air-birds.js`（会被惊飞的鸟）、`72-air-chapters.js`（每一章摆什么）。主角脚边（走的那条线前后两三米以内）的东西在 `48-feet-kit.js`（电缆、托盘、油桶、纸箱、管子、隔离桩、花盆、石笋……很多小零件烘成一个网格）、`49-feet-life.js`（会逃的老鼠和蚂蚱、跑过去被带起来的纸片和花瓣、被踢开的易拉罐）、`73-feet-chapters.js`（每一章分四组摆：脚下、身后、身前、会动的；地址后面加 `?feet=0` 一样都不摆）。
- 画布上的柔边（虚化）一律用 `10-core.js` 的 `blurDraw`，不要用画布自带的 `ctx.filter = 'blur()'`：iPhone 上没有它，柔边会全变成硬边。
- `Last/sidescroller/build.sh`：把 `src/` 和 `escape/` 拼成一份 `Last/escape.html`（二十二章怎么接成一条路，见上面“《逃出工厂》故事灰模”的“源码”一条）。改完源码后运行 `bash Last/sidescroller/build.sh`。
- `Last/escape.html`：拼好的页面，二十二章都在里面。原来单独的旧原型页面 `Last/sidescroller.html` 已经并进来，不再生成。
- `Last/sidescroller/escape/`：《逃出工厂》六章和结尾的源码，一章一个文件，`60-kit.js` 是共用的（焚化炉那一章的 `61-e1-furnace.js` 删掉了）。

## 水下实验室（第 23 章）

打开 `Last/escape.html?ch=23`，或按 Esc 在章节菜单选择“水下实验室”。从岸边下水，按 ↓ 潜到海床，在入口阀门旁按 E 打开闸门；向右游过通道，再按空格从内部水井上浮、向右上岸。实验室内的控制台按 E 恢复供电，完成探索。入口上方有实体墙，不能绕过闸门。上岸后有存档点；重新开始章节会重置闸门和电源。游泳时也支持操作普通 E 机关。
