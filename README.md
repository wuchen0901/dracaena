# 小游戏

这个仓库现在只留 `mini/` 里的两个解谜小游戏：棱光、夜里的房子。主游戏《The Last Light》（原 `Last/`）和小游戏《灯下》《门厅》2026-11-19 按仓库主人的要求删了，代码在 git 历史里（删除前的最后一个提交是 `9e08d93`）。下面的说明里还提到它们的地方，都是历史记录。2026-11-19 又清掉了主游戏留下的设计文档、效果图、音频，只留夜里的房子用的（`design/night-*.md`、`generated_images/` 里的 house、worlds 图）。

## 小游戏（`mini/`）

2026-11-17 主游戏的画面先放着，另做了两个画面简单的解谜小游戏试试手感，和 `Last/` 互不相干。都是单个 HTML 页面，不用联网、不用构建，直接用浏览器打开就能玩；电脑上用键盘，手机上点屏幕。2026-11-18 又加了一屏点击解谜的试验（门厅），接着把它扩成一整栋连在一起的房子（夜里的房子）。

- `mini/index.html`：入口页，每个游戏一张卡片。
- `mini/prism.html` · **棱光**：光束反射。点镜子，镜子转 45°；点棱镜，棱镜翻面。把光引到所有晶体上就过关。白光过棱镜分成红、绿、蓝，颜色可以混（红 + 绿 = 黄，三色合起来又是白），晶体要的颜色多一种少一种都不亮。8 关，有撤销、重来、两级提示（第一下圈出该转的那一个，第二下画出该转到的角度）。手机竖着拿时关卡自动转 90°。
- `mini/house.html` · **夜里的房子**（2026-11-18）：门厅那一屏扩成一整栋房子。主人要的是“关卡不要做成独立的，第一关过了直接走到第二关，所有关卡在一张图里，不切换屏幕”：整栋房子是一张连着的图（剖开来看：楼上、楼下、地下室），镜头跟着孩子走。先画了一张平面安排（`generated_images/house-plan-01.png`），主人说“就按照你说的做”。
  - **操作改成拖着走**（2026-11-18，主人说“左右滑动屏幕、人物左右走”比“点哪儿走到哪儿”好，要默认拖着走，加个开关能回到原来的样子）：手指按住往左、往右拖，孩子就往那边走，拖得远就小跑，松手就停；往回拖马上掉头（拖远了，按下去的那一点跟着手指走）。走到楼梯口、梯子跟前往上、往下拖就上下楼（离楼梯口、梯子不到 440 就自己走过去）。楼梯中间的平台拐过去不用换手：一直按着往右拖，下楼梯、拐过平台、下到门厅。手指底下什么都不画（2026-11-19 主人说滑屏幕的时候不要那个圈，“甚至不要有任何手操作的显示”：原来手指按下去的地方画一个淡淡的圈、手指在圈里的哪儿画一个小圆，长按推东西时手指底下一圈慢慢画满，都去掉了，操作没变）。点东西照旧：点了就走过去用它（走的路上一拖就不走过去了，听手指的）；点空地不走。物品栏、提示、规则都没动。电脑上用 ← → ↑ ↓ 或 WASD，按住一会儿就小跑起来。

    - **推、拉东西改成长按**（2026-11-18，主人说点一下脏衣篓它就自己推到地方“太不受控制了，而且太无脑了”，要“长按屏幕，手放到箱子上，再滑动就推”）：孩子站在脏衣篓（厨房的椅子也一样）旁边（离它这一边站的地方不到 90），手指按住屏幕上随便哪儿不动，过 0.28 秒（手指底下不画东西），孩子就两只袖子搭上去；手指不松开往左右拖，人和东西一起走 —— 往外拖是推，往自己这边拖是拉（身子往后仰、倒着走），拖得远走得快一点，推到头会咚一下停住；松手就放开，东西停在哪儿就是哪儿。孩子不在旁边，按多久都没反应。（第一版是要按在脏衣篓上，主人说是“按住屏幕上任何一个空的地方”，同一天改了。）规则里还是只有“推到了 / 没推到”两种：松手的时候离头不到 15%（脏衣篓离灯绳底下、椅子离冰箱门），它再滑一点靠上去，算推到了；不然就算没推到（推到了又拉回来也一样，椅子拉开了冰箱门就关上）。点一下脏衣篓、椅子不会自己推了：孩子走过去摸一下，上面出一行字“站在它旁边，按住屏幕不放，孩子就把手搭上去；再往左右拖”；头一回站到它旁边、右上角 ? 指到它们的时候也出这行字。电脑上走到跟前按住 E（或空格）抓住，再按 ← →，松开 E 放开。`?ctl=tap` 照旧是点一下自己推过去。代码在 `PUSHABLE`、`nearPushable`、`requestGrab`、`startGrab`、`grabUpdate`、`grabEnd`、`grabTick`，画面上用的是原来推、拉的姿势（`pushK`、`pull`）。
      - **点东西要走到跟前**（2026-11-18，主人说：点了地上的一样东西，人就冲过去，“万一我不小心按到一个下面楼层的按钮，这个人就猛劲地莫名其妙往前冲”）：拖着走的时候，点一样东西（地窖口、脏衣篓、椅子也算），只有孩子走过去不到 240（同一间屋子里几步路）才去用它；远了（别的楼层、隔着半间屋子）不动，什么都不说，和点空地一样（同一天先是出一行字“走到它跟前再点”，主人说这样就暴露了那是一个线索，去掉了），手里拿着的东西还拿着。代码在 `REACH`、`withinReach`。`?ctl=tap` 照旧点哪儿都走过去。

      - **开场灯崽带路**（2026-11-18，主人说开场左边那盏台灯意义不大，挑了“让灯崽带路”）：开场 2.2 秒，卧室的灯崽吱一声从台灯里钻出来，走到床边插头旁边（`GUIDE_X` = 556）坐下，朝着插头，隔两三秒原地蹦一下，用自己的光照着地上的插头和墙上的插座。不出字。带路的时候孩子从它旁边走过它不躲；孩子走到它跟前（110 以内）或者插头插上了，就算带完了，它照平常那样吓一跳（被堵在墙角就从孩子头顶翻过去）跑开，过一会儿回台灯，以后不再带路（`m.guide`：1 走过去、2 坐着等、3 带完了）。它的光照不到睡袍（离睡袍的头 700 多，光只有 180），睡袍一直立着，谜题没变。查过：开场 3 秒钻出来、6 秒坐到插头旁边，一直坐着蹦；孩子往右走到 456 它跑开、翻过孩子头顶、回到台灯；整段时间睡袍一直立着；截图看过它坐在插头旁边、插头和插座被照亮；照最短的解法照旧走出前门、没被抓。
      - **物品栏里画成屋子里的样子**（2026-11-18，主人问能不能“道具在地上是什么样的，在道具栏里面也显示什么样”）：物品栏、气泡里、捡起来飞到物品栏的那一下、电脑上跟着鼠标的那一个，都不再用原来那套冷色的小图标，改成用屋子里画它的同一个函数（`sceneItem`）在灯下的颜色画：紫色的拖鞋、棕色的柴、白身子铜帽的保险丝、绿玻璃的萤火虫罐子（亮着的时候里面的萤火虫照旧一闪一闪）、铜灯头的灯泡、铜钥匙、铜摇把。先照世界里的大小画一张大的，量出画了的那一块，等比缩到格子里（`ICON_SIZE`、`iconCanvas`、`drawScene`）；拿在手里的那一格照旧靠格子变成暖色、东西上下浮动看出来。原来的小图标（`drawItem`）删了；气泡里不是东西的小图（插头、脏衣篓、闪电、箭头……）没变。两种玩法都一样。查过：`check.mjs` 通过；电脑、手机横屏截图看过物品栏六样东西和气泡里的灯泡；照最短的解法走出前门、没被抓、没报错。拖鞋还是屋子里那只侧面的拖鞋（以前气泡里侧面的拖鞋主人说像馒头，才换成从上往下看的一双；现在有颜色了，要是还认不出来再改）。

      - **开着的抽屉、柜子、冰箱、钟门不会再被点关上**（2026-11-18，主人说“经常打开一个抽屉 柜子 冰箱 想拿里面的东西，结果把它又关上了”）：里面的东西（灯泡、保险丝、蜂蜜、摇把）能点的框很小，又在抽屉（柜子、冰箱、钟）的大框里面，手指稍微偏一点就点到了外面那个大的，规则里点它就是开 / 关。改了两处：一是开着、东西还在里面的时候，点在抽屉（柜子、冰箱、钟）身上哪儿都算拿里面的东西（`spots()` 里的 `hit`；提示的圈还是圈着那样东西）；拿走以后，开着的空抽屉不算能点的东西。二是规则里这四样开了就开着，再点不会关上（关上本来就没有用；冰箱是椅子顶着的，椅子拉开了，门照旧关上）。最少还是点 26 下，没有死路；局面从 14 万个变成 4 万 3 千个（少了“关上”这一步），提示搜得更快。门厅（`mini/hall.html`）的抽屉、钟门一样改了。查过：`check.mjs` 通过；无头 Chrome 里四样都打开、东西在里面的时候，点在离东西远的地方（抽屉角上、柜子那一头、冰箱下半截、钟的上半截），都是拿到了东西、开着没关；点在框外一点（手机上手指偏了）也拿到了；空了的抽屉、柜子、钟门点了没反应，空了的冰箱点到的是顶着门的椅子，只是摸一下；关着的照旧点一下打开；用鼠标真的点抽屉角上，拿到了灯泡；照最短的解法 26 下走出前门，一次没被抓；控制台没有报错。没在真手机上试。
