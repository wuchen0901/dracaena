## 每关都一样的规矩

- 规则还是第 1 关那一条：灌了墨的衣服在暗处醒着，在自己那一片里追孩子；光照到它的头，它就塌下去，变回一件普通的衣服。孩子不敢走过醒着的衣服，被碰到就回到最近一盏照着他的灯底下，做过的事都还在。（故事挑了 C 的话，转折以后改成被抱走一只跟着的光，见 `docs/night-story-pitches.md` 的 C。）
- 算光的：灯、火、活的光（不管什么颜色都算）。不算的：月光、绿色的应急灯、信号灯的绿灯这些冷光，只是好看。
- 不出字。点错了，用动作和气泡里的小图告诉你差什么；卡住两分钟以后，能用的东西才慢慢闪。
- 每关的东西在这一关里拿、在这一关里用完。走进下一关的时候物品栏是空的（多拿的、没用上的，孩子在门口放下）。这样每关的规则是单独的一段，求解器一关一关地搜（走得出去、没有死路、少点哪一处都走不出去），提示只搜这一关，存档也只记这一关。跟着的小光要是算数（见下面一条），也一样：每关进门手里有几只是定的，这一关里用完，剩下的不带进下一关。
- 一关大约 7 分钟：5–7 间屋子或几段路，6–7 道“怕”，最少点 20–30 下。歇一歇的几关短一点（5–6 分钟），大的几关长一点（8–9 分钟）。
- 每关只加一两样新的光、一种新的衣服。先在不危险的地方教一遍，再在要紧的地方用；后面的关再拿出来，和别的合在一起用。
- 每一步都要是生活里说得通的（主人说过“萤火虫烤暖发光这事我都没听说过”）：插电、拉绳、开门、添柴、开风门、换保险丝、拧灯泡……世界里唯一不讲道理的就是“灯光让衣服塌下去”这一条（C 转折以后多一条和它连着的：把一只活的光递给衣服，它抱着光变成一盏灯）。
- 跟上来的小光：故事挑了 C 的话，转折以前（大约第 7 关以前）只是好看，转折以后算数（被衣服碰到是被抱走一只，可以分给衣服让它变成一盏灯），见 `docs/night-story-pitches.md` 的 C。只是好看的时候：亮度和第 1 关飞出来的萤火虫一样（0.3），不算“照到”，碰不到规则。衣服一靠近，它们全钻进孩子的大衣里（大衣大一号，正好装得下），过去了再钻出来。

## 做法（技术上）

2026-11-20 做第 2 关的时候走到哪一步了：**规则已经一关一段**（`games/house.html` 的 `<script id="core">` 里“一关一段”那一节：每关一组 START / ITEMS / VALUES / GATES / LINKS / SPOT_ZONE / act，`check.mjs` 一关一关搜，第 1 关那一行和分关以前一字不差）；**页面还在一个文件里，没拆**；室外的画只留镜头附近的也还没做（院子的三块画布都留着，天和远景单独一层）；存档记的是并起来的整个局面（`house.save.v3`），不是“第几关 + 这一关的状态”。下面是原来的打算，拆文件的时候照着做。

- 现在 `games/house.html` 一个文件三千七百多行，只有一关；二十来关放在一个文件里放不下。拆开：一个页面（比如 `games/night.html`），共用的部分（画法、光、孩子、衣服、走路、拖着走、物品栏、提示、存档、声音）一个文件，每关一个文件（这一关的屋子、东西、规则、画）。还是不用构建、不用联网：页面里用 `<script src>` 一个个载进来，双击打开也能玩。
- 坐标接着往右排：每关有自己的原点，前一关的出口接后一关的入口（以前主游戏 `escape.html` 里 `X9 = X8 + 266` 就是这么排的，主游戏已经删了，在 git 历史里）。
- 规则一关一段：每关自己的状态、`act`、`GATES`、`LINKS`；`check.mjs` 一关一关地搜。两关之间的那道门，就是“这一关走出去了”。
- 画：第 1 关每间屋子暗的、亮的各画一张放着。一百多间屋子全放着太占内存，手机上更不行 —— 只留镜头附近（前后一关）的，远了就扔掉，走回来再画。
- 存档：记现在在第几关、这一关的状态、最近一盏灯；前面的关都当作做完了。
- 量深浅（2026-11-24 起）：`node tools/check.mjs` 最后多一段“深浅”，每关报最少点几下、“岔开”多少（局面 ÷（最少点 + 1）：1.0 是一条直线，每一刻只有一件事做得成；第 1 关 800 多），再列出最少点不到 15 下、差不多一条直线（不到 1.5）的关。只报数，不算 BAD。
- 做的顺序：先拆文件，把第 1 关原样搬进去（玩起来一模一样，`check.mjs` 结果一样）；再做第 2 关（第一次到外面，要先定外面怎么画：天、地、远景）；之后一关一关往下做。每关做完：`check.mjs` 过一遍，无头 Chrome 里照最短的解法走一遍，主人玩一遍，再做下一关。
