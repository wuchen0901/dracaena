# 夜里：去掉跟着孩子的东西（2026-11-25）

主人说：“把跟着主角的乱七八糟的东西去掉。”跟着孩子的有三样，问过去到什么程度（只去不算数的 / 全去掉、谜题一起改 / 只去灯崽），主人选的是**全去掉，谜题一起改**。2026-11-23 主人说过“让它们有用，不是删掉”，这一回是后来的、也更明确的意思，照这一回做。

## 去掉了什么

1. **灯崽**（脚边一路跟着的黄毛球）：不再跟着孩子；点它拿起、再点地面放下当小灯（`docs/night-orb.md`）整套没了；八关里“要灯崽停在灯座上”的谜题（`docs/night-orb-puzzles.md`）没了；孩子被衣服追的时候钻进大衣、第 21 关以外各关“藏在大衣里”也跟着没了。
2. **肩头飘着的小光点**（第 7、8、9、11 关进门飘在肩头、递给衣服的）：孩子身边不再飘东西。
3. **一对带翅膀的小灯虫**（第 2 关车灯里救下来的，卷帘门撑起来以后跟着孩子走）：整段去掉。
4. 第 14 关（地下最深处）人群冲上来“把肩头的小光抱走”：小光没了，这一段只剩人群冲上来、停一会儿、退回去（孩子蹲下发抖 3.8 秒，和以前一样）。

### 递光（第 7、8、9、11 关）

规则**一个字没动**（`sGive` `gGive1` `gGive2` `nGive` `uGive`，`sKid` `gKidH` `gHand` `nHand` `uHand` 那几处点它的步骤、`GATES`、`LINKS` 都是原样）：点窗边那件小孩的衣服、长凳上的外套、器材室里跑圈的运动服、烤串摊的摊主、弹琴的外套，就是原来的那一步。变的只是画：以前是孩子肩头那一只（两只）小光飞过去，现在是点了以后它怀里（弹琴的外套是脚边的小灯）的灯慢慢亮起来（0.7 秒），孩子身边什么都不飘。点不成的时候气泡里画的 `orb` 小图照旧（表示“要一点光”）。
