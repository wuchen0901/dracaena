# 夜里 · 第 21 关（前半）：钟楼顶的大灯（做成的样子）

2026-11-23。第 21 关分两个任务由两个人先后做。这一页写**前半**：照 `docs/night-story-c.md`“结局”一节第 1–3 点做到“大灯亮了、天亮了”，孩子站在钟楼顶；**后半（第 4–12 点：下钟楼、敲钟人回来、坐末班车、上坡回家、门厅、推门、合影）没做**，这一页最后一节“给后半接着做的人”写了从哪儿接、怎么接。

做出来最少 **5 步**（`node tools/check.mjs`：第 21 关 5 下、10 个局面、没有死路、少点哪一处都走不出去、走出去时身上不带东西）；加上走完以后那一段不出字的小动画约 17 秒，自动试玩从钟房的小门走进来到动画完约 25 秒，真人玩估计两三分钟（没有亲手玩）。新的东西：**发条钥匙、铁坨（备用的重锤）**；新的办法：**发条上弦、挂重锤、脱扣杆**；这一关没有新的光（只有最后那盏大灯），也没有新的衣服（见“没做 / 有疑点的”）。

代码在 `games/house.html` 里。直接玩第 21 关：地址后面加 `?lv=21`（前二十关照最短的解法当作走完，孩子站在钟楼顶小棚的门口；不读也不写存档）。从第 20 关一路玩进来：`?lv=20`（或不带 `lv` 从头玩）。

## 一步一步

最少 5 步，名字都用 `j` 开头（先 grep 过：全游戏原来没有 `j` 加大写字母开头的名字；小写 `jt`、`jm`、`jacket`、`jk*` 等是别的东西，没有冲突；`tools/check.mjs` 查规则里的名字不重，通过）。机关的道理：灯罩的铁片被链子拴着，链子绕过柱顶的滑轮，链钩空着；发条箱管着机关的擒纵（走得慢、走得匀），没上弦它就是死的；一块备用的重锤扔在地上。

1. **拿发条钥匙**（`jKeyH`）：小棚墙上的钩子。
2. **给发条箱上弦**（`jSpringH`，手里拿着钥匙）：钥匙插在方头轴上拧，发条越绕越紧，棘轮咔嗒咔嗒响；钥匙留在轴上（`jKey` = `used`）。空着手点：拧不动，气泡里画钥匙。
3. **拿铁坨**（`jWtH`）：地上。
4. **把铁坨挂上链钩**（`jChainH`，手里拿着铁坨）：空着手点，勾不动，气泡里画铁坨。
5. **拉脱扣杆**（`jLeverH`）：没挂铁坨拉不动（气泡里画铁坨），没上弦拉不动（气泡里画钥匙）。这一步做成就是 `jLit = 1`，下面那一段小动画从这一刻开始。

（1 一定在 2 以前，3 一定在 4 以前；1、2 和 3、4 两串互相不管先后；5 一定在 2 和 4 以后。）

规则一关一段（`START21`、`ITEMS21`、`VALUES21`、`GATES21`、`LINKS21`、`SPOT_ZONE21`、`act21`、`L21`）：状态 `jKey`（hook / inv / used）、`jWt`（floor / inv / used）、`jWound`、`jHung`、`jLit`；点 `jKeyH`、`jSpringH`、`jWtH`、`jChainH`、`jLeverH`（都在一整块平台 `j0` 上，没有隔开的地方）。**这一关没有吓人的衣服**（`GATES21` 是空的）：骨架里写“街上的衣服都朝钟楼走、给他让路”，到钟楼顶以后没有衣服可吓，所以没有“被衣服吓回来”的地方（这条和每关都要有被衣服吓回来的惯例不一样，要主人看）。

## 脱扣杆以后：不出字的小动画（约 17 秒）

脱扣杆一拉，`commit` 里记下 `V.jT0`；`V.jU` 就是这以后的秒数（没拉是 -1）。**所有会动的东西都是 `jU` 的函数**（`jUpdate`、`drawJDyn`、`drawJGlow`、`drawJSky`），所以读档、`?lv`、截图一步到位就是把 `jU` 摆到最后（`snapTo` 里 `V.jT0 = V.T - 99`）。孩子这段时间是 `wait`（站着看，面朝大灯），点什么都没反应，到 `JU.done` 才放开。时间表（`JU` 这个常量表里能改）：

| 秒 | 发生什么 |
|---|---|
| 0.3–2.9 | 铁坨慢慢往下沉，拉环转，14 片铁片一片一片侧过去（棘轮声）；罩里一点点透出光 |
| 1.6–4.3 | 挤在罩外面的 46 只小光（一直在那儿，脱扣杆以前就绕着罩子转、进不去）一只一只螺旋着钻进去，灯亮一点 |
| 2.2–8.5 | 一路上分出去的、被抱走的光：40 个光点，从画面最左边外面一串飞来（在画面上从左到右拉得很长），弧线飞进灯里；每一个进去灯再亮一点 |
| 6.0–9.4 | 灯崽（座钟里那只）从左边蹦着跑来，站在孩子跟前（6–7.2 跑，7.2–8.2 站着眨眼看孩子一眼），然后弧线飞进大灯（8.2–9.4） |
| 9.4 | 大灯醒了：一闪（`snd.win`、`snd.lightOn`），钟面亮了（`V.jdl`），灯光满了（`V.jI` = 1） |
| 9.6 起 | 光一圈一圈扫出去（4 圈，间隔 0.9 秒，每圈 650 单位/秒）；`jl` 这盏灯的半径（`V.jR`）从 380 涨到 2280，整个平台由暗处的画换成亮处的画（有颜色） |
| 10–14 | 镜头往后拉：`V.jZoom` 1 → 0.78（见下面“镜头”） |
| 10.8–16.3 | 天亮：`V.jDawn` 0 → 1，天空盖上一层早晨的颜色（上蓝下暖黄）；11–16.3 月亮落到右边的山后面去（`V.jMoon`）；钟面上的时间从 11:35 一路走到 6:00（`jMin`，带滴答声）；家里的窗在 11.0、11.6、12.2 秒一扇一扇亮起来，卧室那扇最先 |
| 16.8 | 小动画完了：`V.jDone = 1`，孩子放开，站在脱扣杆跟前（x 69844）；`V.safe` 放在这儿 |

灯崽是**只画不动引擎**的（`jImp`，用 `drawImpBody`、`drawImpFace`，没有腿）：引擎里那只灯崽跟着孩子，但它的路 `clamp` 到 `YARD_END`（67300，钟楼底层），到不了钟楼顶；这里就另画一只。小光和那一串光点也都是 `drawJGlow` 里画的光点（`jMotes`、`jStream`），不是引擎里的 `V.swarm`。

## 镜头往后拉（新的做法）

引擎里没有放大缩小，这一关加了一个：`Z0` 是照屏幕算出来的原来的放大倍数，`ZNOW` 是现在乘了几；`applyZoom(m)` 把 `Z`、`VWW`、`VHH`、`K`、`LS` 一起按 `Z0 * m` 重算（`layout()` 里 `Z0 = Z`、窗口变了再套回去）。`V.jZoom` 是现在的 `m`，`jUpdate` 里每帧向目标走（`dt * 0.055`，约 4 秒走完 0.22），目标是 `u > JU.zoom0 ? 0.78 : 1`。点哪儿走哪儿、物品栏这些用的都是现在的 `Z`，所以拉远以后照样对得上。屋子的画本来就是按 `RS` 画好的位图，缩小只是缩着贴，没有重画；光的排线（`TONE`）缩一点不重建，线会细一点点，看着没问题。**后半不想要拉远的镜头，就改 `jUpdate` 里的 `zt`**（比如孩子离开钟楼顶以后目标改回 1）。

## 引擎里动了哪几处

- `ROOMS` 多 `jA`、`jB`（`fr` 改成 560）；`NODES`、`EDGES` 多一个点对一条路；`ROOM_PAINT`、`drawDynamic`、`LIGHTS`（多一盏 `jl`）、`ICON_SIZE`（`jKey`、`jWt`）。`YARD_END` 没动，还是 67300（它是第 20 关底层的路尾，灯崽的路用它）。
- 镜头：钟楼顶（`S.hOut && V.jIn`）右边的界是 `J.x1 + 10`；孩子在 x > 68500 的时候往上最多看到 y = -620（天空那张图的顶）；`peek` 的右界同样。
- 第 20 关走进小门不再结束游戏：`tick` 里 `kid.x <= TWP.exit + 3` 就 `jEnter()`（孩子淡出、`placeKid` 到钟楼顶的门口、镜头保持原处慢慢摇过去、淡进 0.9 秒、`V.jIn = 1`、记一次存档）；孩子的透明度 `kid.alpha` 在 `S.hOut` 以后归 `jIn` 管。
- 存档：`SAVE_KEYS`、`SAVE_VALS` 多第 21 关那几项；`writeSave` 在 `S.jLit`（拉了杆以后）和“走进小门还没淡进”的时候不写；`readSave` 里 `jLit` 的存档当作走完了的不读，没走出小门（`!hOut`）就有第 21 关的东西变了的也不读。读回来：站在 `V.safe`（钟楼顶的门口，或者你自己放的灯底下）、物品栏、发条上了弦没有、铁坨挂上没有都对。
- 提示（`?`）：`hint()` 里 `jSpringH` 画钥匙和箭头、`jChainH` 画铁坨和箭头、`jLeverH` 画箭头；卡住两分钟后闪的小星星（`jglints`）：钩子上的钥匙、发条箱的轴（拿着钥匙）、地上的铁坨、链钩（拿着铁坨）、脱扣杆（上了弦、挂了铁坨）。

## 给后半接着做的人（第 4–12 点）

**从哪儿接**：`S.jLit` = 1 并且 `V.jDone` = 1 的时候：大灯亮着、天是早晨、镜头拉远（0.78）、孩子站在 (69844, -20) 面朝右、自由。`jLit` 现在是 `L21` 的 `GOAL`。

**怎么续**（都在同一个 `L21` 里，不另起一关）：

1. **规则**：往 `START21` 加新的状态（比如 `jDown`：下到钟楼脚下；然后第 5–10 点各自的状态），`VALUES21`（三个值的项）、`SPOT_ZONE21`、`act21` 加新的 `case`；`L21.GOAL` 换成后半最后一个状态（合影拍完的那个）。`tools/check.mjs` 不用改，自动会跑；但**要保证 `jLit` 以后的新步骤也没有死路、走出去身上不带东西**。后半的点要在 `jLit === 1 && V.jDone` 以后才出现：`spots()` 里“钟楼顶（第 21 关）”那一块加 `if (S.jLit && V.jDone) {…}`，`ACT` 里 `id in SPOT_ZONE21` 已经管着了（它给规则 `new Set(['j0'])`，要分块的话照第 20 关 `twZoneAt` 的写法改）。
2. **下钟楼的入口**：就是孩子进来的那扇小棚的门：`JP.door` 68560（门框 68556–68652，门脚 y = -20，孩子站在 `JP.in` 68680 向左走过去），画在 `paintJ`（`jA`）里，是钟房那扇小门的另一面。往下走的路：从这扇门“传”回钟房（**照 `jEnter` 反着来**：孩子淡出、`placeKid(TWP.exit + 70, TWY2, -1)`、`camFX/camFY` 保持原处慢慢摇、淡进），再沿第 20 关那几条路（`EDGES` 14→13 软梯→12→11 木楼梯→10 号路街面）往下走；软梯和楼梯现在都是放下来、能走的（第 20 关做完的样子，`S.hWind = 1`）。钟房里站着敲钟人的衣服（画，`V.hg`，原来站在小门边 x 67220）、一层墙上的油灯点着（x 67910，灯芯 y 156）：“敲钟人回来了，手里的油灯点着了，朝他抬一下手”可以做在钟房或一层（画法见 `twGuide` / `klWalker`），或者让孩子走到钟楼脚下（街面，x 66260 是大门）再让他从大门出来。
3. **镜头和天**：天亮是 `V.jDawn`（从 `jU` 算出来，到最后一直是 1），`drawJSky` 在屋子后面盖一层早晨的天、画月亮和山，**只要 `S.hOut` 且镜头左边在 `J.x1 + 600` 以内就画**，所以孩子下到钟楼里面、街上去，天一直是早晨（月亮已经落下去了）。但是：大灯的光 `jl` 的 `clip` 只到钟楼顶这两间屋子 `[J.x0 - 10, -700, J.x1 + 10, 640]`，下到钟房、街上以后那儿还是“夜里的画”（暗的那一层）：要街上也亮，就在 `LIGHTS` 里 `jl` 后面再加一盏“早晨的光”（半径很大、`clip` 盖住那一段，`I` 用 `V.jDawn`），或者给 `drawBg`、屋子的画加早晨的颜色；钟楼脚下第 18 关的广场、木马、街上的人“一点点回来”（第 3 点后半）也要在这里做。镜头的远近：`V.jZoom`（`jUpdate` 里 `zt` 是目标）；拉远了 0.78 以后默认就一直留着，要回到 1 就改 `zt`。
4. **别碰的**：`jImp`（只在 `JU.imp0`–`JU.imp3` 之间画）；`jUpdate` 里的 `V.safe`；`jDone`；`drawJGlow` 里的小光和光点（`jMotes`、`jStream`，进了灯就没了）；`writeSave` 里 `S.jLit` 不写、`readSave` 里 `s.jLit` 不读：**后半一做就要改这两处**（改成后半最后一个状态，并让读回来站的地方、`V.jDone` 的值对得上；`snapTo` 里 `jDone: S.jLit`、`jZoom: S.jLit ? 0.78 : 1` 这两项也是）。
5. **名字**：这一关用 `j` 开头（状态 `jKey`…`jLit`，页面里的画和更新 `paintJ`、`drawJDyn`、`drawJSky`、`drawJGlow`、`jUpdate`、`jEnter`、`jStart`，常量 `J`、`JP`、`JR`、`JU`、`JN`、`JHOME`、`jMotes`、`jStream`）。后半接着用 `j`，不会和别的关冲突；`won`（出现“再来一遍”）全游戏还没有人设，最后的合影做完再设。

## 没做 / 有疑点的

- **没有吓人的衣服**（见上）；骨架第 3 点里“光扫过的地方衣服里的墨退下去、人回来、街上一点点有了人、木马上大人搂着孩子”**没做**（只做了光一圈一圈扫、窗亮、天亮、月亮落，镜头拉远）；“被抱走的光从各处的衣服怀里飞出来”只是一串光点从画面左边飞来（没有从具体的衣服里出来，那些衣服在这里看不见）。
- 灯崽是另画的一只、没有腿（蹦着走、飞）；站着看孩子的时候眼睛朝右、会眨眼，没有“回头”的动作。
- 钟面上的时间：11:35 一路走到 6:00，我自己定的（骨架没写）；滴答声用现成的 `snd.tick`，没听过（无头 Chrome 里没有声音）。
- 铁坨往下沉、拉环转和铁片开的对应只是画个意思（沉 86 单位，铁片开一圈）；发条箱管擒纵、铁坨管力，这个解释没有画出来，只靠气泡和动作让人觉得“两样都要”。
- 拉远的镜头：光的排线缩一点没重建（线会细一点）；高分屏（`DPR` 2）、很宽或很窄的窗口没有逐个试，只试了 1280×720 和 844×390。
- 动画 16.8 秒里孩子一直站着、点什么都没反应，没有“跳过”；动画中途刷新页面会回到拉杆以前（不存档）。
- **没亲手玩，没在真手机上试**；声音没听过。
